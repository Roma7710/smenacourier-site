# СМЕНА

Лендинг партнёрской программы по подбору курьеров.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

## Сборка

```bash
pnpm build
```

Готовая Cloudflare Workers-совместимая сборка создаётся в `dist/`.

## Приём заявок

По умолчанию форма работает в демонстрационном режиме и честно сообщает, что данные не отправлены. Перед публикацией подключите обработчик:

```html
<script>
  window.LEAD_ENDPOINT = 'https://example.com/api/lead';
</script>
```

Обработчик должен принимать POST-запрос с JSON и возвращать успешный HTTP-статус.

## Основные файлы

- `index.html` — структура и тексты страницы;
- `assets/styles.css` — визуальная система и адаптивность;
- `assets/app.js` — калькулятор, форма и интерактивные элементы;
- `public/og.png` — превью ссылки;
- `worker/index.js` — точка входа для хостинга.
