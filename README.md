# СМЕНА

Лендинг партнёрской программы по подбору курьеров.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

## Сборка

```bash
pnpm build
```

Готовая Cloudflare Workers-совместимая сборка создаётся в `dist/`.

## Приём заявок

Для GitHub Pages задайте публичный HTTPS-адрес обработчика в переменной репозитория `LEAD_ENDPOINT` (Settings → Secrets and variables → Actions → Variables). После изменения переменной заново запустите workflow **Deploy GitHub Pages**. Для локальной сборки можно задать ту же переменную в окружении.

Обработчик принимает JSON с полями `id`, `name`, `phone`, `consent` и подтверждает приём ответом 2xx. Укажите в CORS хосты лендинга, включая `https://smenacourier.ru`, и разрешите метод POST с заголовком `Content-Type`. Токены приёма заявок должны храниться у обработчика.

При пустой переменной форма открывает черновик сообщения в личном чате Telegram. Посетитель подтверждает отправку в Telegram. Экран благодарности на сайте показывается после подтверждения приёма HTTP-обработчиком.

## Основные файлы

- `index.html` — структура и тексты страницы;
- `assets/styles.css` — визуальная система и адаптивность;
- `assets/app.js` — калькулятор, форма и интерактивные элементы;
- `site.config.js` — реквизиты, ссылка на Telegram и адрес формы;
- `public/og.jpg` — превью ссылки;
- `worker/index.js` — точка входа для сборки Cloudflare Workers.
